# Node.js 反向代理服务器

不用配置麻烦的环境问题

Required:

- ubuntu 16.04 +
- Node.js

```bash
# 安装 npm
sudo apt-get install npm
# 管理软件
sudo npm install -g n
# 安装最新版本的 Node.js
sudo n latest
```
